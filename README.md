- # Astrolabe · 星盘

  **读懂代码的坐标系。**

  > 你读懂的每一行代码，都有人带、有人确认、留得住。

  ---

  ## 问题

  学一个陌生的开源项目，你大概会连撞四道坎。

  ### 1. 第一道坎：不知道从哪看起

  你打开一个不认识的项目。几万行代码。
  README 只告诉你怎么安装。

  你想知道的是：**从哪个函数开始读？谁调用谁？哪里才是核心？**

  没有人回答。于是大多数人**关掉它，去干别的了**。

  ### 2. 第二道坎：看懂了，但不敢信

  面对一段复杂的代码，你问 AI 它在干什么。它给你一个很像样的解释。

  ⚠ 但你没有第二个来源去对照 —— 它可能是对的，也可能**一本正经地编**。（我在读 Linux 内核的时候，就遇到过好几次。）

  更遗憾的是：**就算你自己发现了 AI 的疏漏，也只能你自己知道** —— 你没办法把这个坑告诉更多人。

  ### 3. 第三道坎：学会了，但留不下

  你今天读懂了，随手记在备忘录里。
  两周后换个项目，读到某处突然想起来："这个我好像见过。"

  ⚠ 但项目那么多、函数那么多，你的笔记**散落各处，找不到**。
  那天想明白的东西，也难以反复品味、加深理解。

  下次再看这段代码 —— **从零开始**。

  ### 4. 第四道坎：想讲给别人，但讲不清

  你想说"这个函数第 30 行有个坑"。

  - 写在博客里，别人打开一看：**行号对不上**（代码早改了）
  - 想把代码贴进正文：太长、太麻烦，而且可能**涉及版权**

  最后只能写成"那个地方有个坑，你自己体会" —— **等于没说**。

  ## 做法

  四道坎，四件事 —— 一一对应。

  ### 1. 有人带你走 → 学起来像闯关

  这里不只有「一堆解释」，还有**别人走过的路线** —— 顺着作者解析出的**代码图谱**，一步步走。

  - 每一步都告诉你 **为什么现在看这个**
  - 从一个入口函数开始，**跟着调用链一步步走**
  - 卡住了？**换一条更适合你水平的路线**（可以复制别人的，改成自己的）

  ⇒ ★ **像走一条已经有人探过的路** —— 而不是自己在几万行里乱撞。

  ### 2. 有人能确认 → 错了会有人指出来

  每条解释都**有作者、可以被评论**。

  ⇒ ★ **写得不对，会有人指出来** —— 就像大家熟悉的技术社区评论区。
  ⇒ 而且纠正**留在原地**，下一个人看到的直接是**修正过的版本**。

  ⚠ 这是 AI 给不了的：**它错了，你只能自己发现**。

  ### 3. 留得下 → 像云笔记，但记在代码上

  在 AI 里提问，答案留在聊天记录里 —— **关掉就散了**。
  在这里提问，它**钉在那段代码上**：

  - 下次打开这个项目 —— **还在**
  - 换电脑、换浏览器 —— **也还在**
  - ★ **而且别人也能看到**（公开项目）

  ⇒ 你记的**不是一段孤立的话**，而是「**我对这个函数的理解**」—— 就钉在它该在的地方。

  ⇒ ★ **1000 个人读同一个项目，不是问 1000 次 AI** ——
  而是**往同一棵树上一起往上加**：你学到的，下一个人直接能用。

  ### 4. 讲得清 → 说「第 12–28 行」就够了

  你不用把代码复制进解释里。只要标出范围：

  > 这里容易看错，见 **`第 12–28 行`**　← 点这几个字，代码就在旁边展开

  ⇒ ★ **因为项目一旦上传就不再改动源码，行号是永久的** —— 半年后回来看，还是那几行。
  ⇒ ★ 解释里**没有代码副本** —— 所以你能放开写，不用贴一大段，也不用担心版权。

  ## 怎么用

  **作为项目的作者：**

  1. **登录** —— 用 GitHub 或 Gitee 账号
  2. **贴一个仓库地址** —— 需要是**你自己拥有版权的仓库**，或者是**允许再分发的开源项目**；再选一个版本（commit）
  3. **等解析完成** —— 打开图谱，开始编写解释，给出阅读顺序的建议

  > ⚠ **不用把每个节点都写完** —— 挑你觉得重要的写就行。
  > 其他学习者会在学习过程中不断补全，最后长成一棵完整的**解释树**。

  **对于其他学习者，进去之后你可以：**

  - 沿着别人做好的**阅读路径**一步步走
  - 在任何一个函数上**写下你的理解**（它会永久留在那儿）
  - 看不懂就**提问**，看到别人写得不对就**纠正**

  ## 关于名字

  星盘（Astrolabe）是古代航海家用来**确定自己在哪**的仪器。
  它不发明星星 —— 它只是把**星空变成可以读懂的刻度**。

  | 星盘 | 这里                                             |
  | ---- | ------------------------------------------------ |
  | 星星 | **代码**（一直在那里，只是陌生）                 |
  | 刻度 | **代码行号**（固定在某个 commit 上，所以不会漂） |
  | 星盘 | **本平台**（不生产内容，只帮你读懂内容）         |

  ⇒ 所以它和代码托管平台**不是竞争关系**：

  - **代码的家在 GitHub / Gitee**（那里是"改代码的人"的地方）
  - **本平台是读懂代码的书房**（这里服务"读代码的人"）
